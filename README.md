# NOCTURNE — A Living Interface

> *"PRESENCE OVER POLISH"*

NOCTURNE is an advanced, atmospheric, and immersive web experience built as an experimental digital interface. It combines dark cinematic aesthetics, deep ambient lighting, and high-performance WebGL/GPU-driven interactive particle fields.

---

## ✦ Core Features
- **Cinematic Atmosphere**: Deep blacks, near-black surfaces, and subtle chromatic ambient lighting (Amber, Rose, Violet).
- **GPU Particle Engine**: Powered by Three.js (r160), supporting 4 dynamic structural states:
  - *Corona*
  - *Galaxy*
  - *Cortex*
  - *Lattice*
- **Adaptive Performance**: Dynamic particle scaling with fallback capabilities for varied device hardware.
- **Living Micro-Interactions**: Smooth section reveals, magnetic CTAs, custom fluid cursor, and keyboard-accessible components.
- **Editorial White Panel**: Intentional high-contrast editorial divergence within a dark universe.

---

## ✦ Architecture & Technology Stack
- **HTML5**: Semantic, accessible markup.
- **CSS3**: Custom properties, responsive grid/flexbox layouts, hardware-accelerated animations.
- **Vanilla JavaScript (ES Modules)**: No build tools, zero npm dependencies, zero framework bloat.
- **Three.js (r160)**: WebGL-based custom particle simulation.
