04 — QUESTIONS

Curiosity
welcomed.

A few things worth knowing about the experience.

What exactly is NOCTURNE? +

NOCTURNE is an experimental digital interface built around generative visuals, responsive motion and an editorial approach to web design.

How does the particle field work? +

The visual field uses Three.js and WebGL to render particles in real time. Their movement can respond to pointer input and changes in the page.

Does it work on mobile devices? +

The interface is designed to adapt to different screen sizes. Visual complexity may be reduced on devices with limited graphics performance.

Does the website respect reduced motion? +

The experience is intended to respect the prefers-reduced-motion accessibility setting. Interactive effects should never be required to understand the page content.
